# JanusVLN\_Tutorial\_Skill\_Version

We also provide a Skill for reproducing the results with the Conda environment package. Simply provide Codex with the Skill file (`tutorial/tutorial/skill/reproduce-janusvln-base.zip`).

However, we have only used the Skill to run a small number of episodes to verify that the workflow functions correctly. The complete evaluation results were obtained using the manual Conda ( 
[JanusVLN_Tutorial_Conda_Version](<../conda/JanusVLN_Tutorial_Conda_Version.md>)) and Docker ([JanusVLN_Tutorial_Docker_Version](<../docker/JanusVLN_Tutorial_Docker_Version.md>)) workflows.
